# Hopcopter 论文笔记（复现参考）

> 来源：Bai, S., Pan, Q., Ding, R., Jia, H., Yang, Z., & Chirarattananon, P. (2024). An agile monopedal hopping quadcopter with synergistic hybrid locomotion. *Science Robotics*, 9(89), eadi8912. DOI: 10.1126/scirobotics.adi8912

## 1. 核心思路

在纳米四旋翼（Crazyflie 2.1）下方加装**被动弹性伸缩腿**，旋翼推力在**空中阶段**（而非支撑阶段）做功：

- 腿完全被动，无腿驱动机构、无触发机构、无变力臂机构 → 机械极简。
- 橡胶带**预拉伸**（预载力 ≈ 3.35 N，约为自重 0.34 N 的 10 倍）→ 支撑阶段可按**质点 + 弹簧阻尼**建模，与重力方向解耦。
- 支撑时间极短（<45 ms，实测约 32 ms）→ 连续跳跃频率高、跳跃高度可调。
- 跳跃模式大幅省电：占空比 0.28 vs 悬停 1.0，续航提升约 3–8 倍。

## 3. 动力学模型

### 空中阶段（AP）

与常规四旋翼一致：

```
m·p̈ = zb·Σfᵢ − e₃·mg
τp  = I·ω̇ + ω×(I·ω)
```

### 支撑阶段（SP，完全被动）

弹性力（式 7）：

```
f_e = −k(l − l₀ − l_p) − sgn(l̇)·f_c   （l < l₀）
```

- 轴向：`m·l̈ = f_e`，固有频率 Ω = √(k/m)，解析可解。
- 角向：绕地面接触点角动量守恒 → `ψ̇(t) = l₀²·ψ̇(t_LD)/l²(t)`。
- 着陆状态（‖ṗ(t_LD)‖、θ_LD）完全决定离地状态（Δψ、θ_TO、‖ṗ(t_TO)‖），即「着陆→离地映射」，是模型控制的基础。

```
ṗ(t_TO) = l̇(t_TO)·zb(t_TO) + l₀·ψ̇(t_TO)·(eψ × zb(t_TO))
```

## 4. 控制架构

高层控制器每跳跃周期执行一次（地面站 Python，100 Hz，经 Crazyradio 通信；低层姿态控制用 Crazyflie 板载）：

1. 预测本周期着陆位置/速度（空中按自由落体 + 无推力处理）。
2. 用支撑模型预测离地状态与下一着陆位置。
3. 数值优化器解代数环：求**期望着陆姿态 zb(t_LD)** 与爬升推力，使下一周期落点误差最小。
4. 推力/姿态管理器：离地后快速回正（z_b = e₃），爬升段推力 Σfᵢ = mg，其余时间推力 ≈ 0。
5. 低层 PID 姿态控制 + 姿态优先推力分配（f = argmin|T_d−T|，约束 fᵢ≥0 且 τ_p,d = τ_p）。

要点：

- 位置控制 = 控制着陆姿态（类似 Salto-1P 的触地角控制），空中轨迹基本弹道。
- 高度控制：动力爬升时间 Δt_PA = z_d/ż(t_TO) − ż(t_TO)/(2g)（不足时），弹道段 Δt_PJ = ż(t_TO)/g + √(2z_d/g)。
- 无滑移约束：arccos(e₃·z_b(t_LD))、arccos(e₃·z_b(t_TO)) < tan⁻¹μ。
- 轨迹跟踪按周期修正（每次跳跃只修正一次），落点参考取下一周期期望位置以消除延迟。

## 5. 气动稳定器（无位置反馈自主跳跃）

- 4.9 g 可拆卸模块：3 个水平铰接气动面（每个 39 cm²）+ 伺服电机（H-King 282AS）+ 拉线。
- 拉紧 = 激活：下落时气流产生力矩，使机体轴向趋向速度反方向（平板理论，z_b → −ṗ）。
- 放松 = 停用：气动力可忽略，爬升阶段姿态控制不受干扰。
- 与姿态控制器**竞争/协同**：稳定器把着陆姿态拉向速度方向，姿态控制器拉向竖直 → 两者平衡出稳定着陆姿态。
- Poincaré 映射证明：单独任一策略都不稳健（仅姿态控制 3–5 跳发散；仅稳定器 6–10 跳发散）；组合后无位置/速度反馈可连续跳跃 56+ 次（45 s，3×3 m 场地）。

## 7. 复现要点与阶段建议

1. **仿真优先（本仓库技术路线）**：Gazebo/ROS2 中先建 Crazyflie 模型，腿用弹簧-阻尼（式 7 参数）实现，做「着陆→支撑→离地」混合动力学。
2. **参数辨识**：复现掉落实验（不同高度自由落体 + 高速相机）标定 k/m、f_c/m、l_p；仿真中可直接用论文参数起步。
3. **控制器分层实现**：先做低层姿态控制 + 姿态优先推力分配 → 再加高层着陆姿态规划与高度控制 → 最后加气动稳定器与 Poincaré 稳定性分析。
4. **真机可选**：Crazyflie 2.1 + 碳纤腿 + 橡胶带即可搭出 35 g 级原型；论文配套代码/数据可参考 Zenodo。
